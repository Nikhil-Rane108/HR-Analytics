# HR-Analytics

[Presentation](https://youtu.be/oOlH3MDjEAY?si=k0xEsyNNbHIx56c-) | [LinkedIn Post](https://lnkd.in/p/dn5Zuc4c) 

## Project Overview
This project focuses on analyzing HR data using **MySQL and Power BI** to understand employee trends, workforce distribution, attendance, salaries, performance, and attrition.

I used SQL to solve 25 business questions and developed an interactive Power BI dashboard to present key insights.

## Tools & Technologies
- MySQL
- Power BI
- DAX
- Power Query
- Microsoft Excel

## Dataset
The project contains five tables:
- Employees
- Departments
- Salaries
- Attendance
- Performance

## Key Analysis
The analysis covers 25 business questions, including:
- Employee headcount and attrition rate
- Salary distribution by department and designation
- Gender and age-group diversity
- Employee performance and bonuses
- Attendance, leave utilization, and absenteeism
- Employee growth and city-wise distribution
- Department-wise attrition and promotion eligibility

## Key Takeaways
- Analyzed employee attrition to understand workforce movement.
- Examined salary distribution across departments and designations.
